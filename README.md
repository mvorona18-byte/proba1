# Яблочный Mini App — Telegram-версия

В этой версии:

- подключён Telegram Web App SDK;
- приложение разворачивается на весь экран;
- отображается имя пользователя Telegram;
- добавлена вибрация при действиях;
- добавлено избранное;
- корзина и избранное сохраняются после перезапуска;
- оформление заказа открывает чат менеджера.

## Запуск

```bash
npm install
npm run dev
```
